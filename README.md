# Trading
This project started as a learning implementation of an algorithmic trading system. 
Monte carlo simulation is done with Python. We tested betting strategies, and it proves how some people have better or worse performance just because of Odds or Random variability, regardless of how good or bad their strategy is. I have coded in Jupyter Notebook. Reference taken from youtube channel "sentdex"
Mini OOP project in Python to understand live data fetching, implementation strategy, execute trades
